# website (Docusaurus) — CLAUDE.md

MagFlip 문서 사이트. 루트 workspaces 에 포함되지 않는 **독립 npm 프로젝트** (Docusaurus 3, TypeScript config, Mermaid).

## 구조

| 경로 | 내용 |
| --- | --- |
| `user-docs/` | 사용자 가이드 → `/user` (preset classic docs) |
| `dev-docs/` | 개발자 가이드 → `/dev` (plugin-content-docs, id `dev`) |
| `sidebars/user.ts`, `sidebars/dev.ts` | 폴더 기반 autogenerated. 순서는 front matter `sidebar_position` 과 `_category_.json` |
| `src/pages/index.tsx` | 홈 (두 문서로 가는 카드) |
| `src/components/FileTree` | 폴더 트리 시각화 `<FileTree nodes={[...]} />` |
| `src/components/DemoFrame` | 로컬 데모 iframe `<DemoFrame />` (URL 끝 `/` 유지 — 데모가 상대 경로 사용) |
| `src/theme/Mermaid` | 원본 Mermaid 컴포넌트 wrapper. 다크 모드 초기 전환 시 같은 id 로 동시 렌더되어 다이어그램이 비는 문제를 colorMode key 로 remount 해 해결. 삭제 금지 |
| `static/img/flip-math/` | Flip 기하 설명 그림 (README 에서도 참조) |
| `scripts/sync-demo.mjs` | `prestart`/`prebuild` 에서 로컬 번들·예제를 `static/demo/`(git ignore)로 복사 |
| `docusaurus.config.ts` | `onBrokenLinks`/`onBrokenMarkdownLinks: 'throw'`, i18n `ko`, `DOCS_URL`/`DOCS_BASE_URL` 환경변수 |

## 명령

```bash
npm install          # 또는 루트에서 npm run docs:install
npm start            # dev 서버 (루트 npm run docs:start 는 build:local 을 먼저 실행)
npm run build        # 정적 빌드 — 깨진 링크 검사. 문서 수정 후 반드시 실행
npm run serve        # build 결과 확인
```

## 작성 규칙

- 대상 구분: 사용자 문서엔 공개 API·예제만, 개발자 문서엔 파일 경로·함수명·내부 흐름.
- 시각화 적극 사용: 흐름 `flowchart`, 호출 `sequenceDiagram`, 상태 `stateDiagram-v2`, 클래스 `classDiagram`, 격자 `block-beta`, 폴더 `FileTree`.
- 문서 간 링크는 파일 상대 경로(`./x.md`, `.mdx` 확장자 정확히). 다른 문서 인스턴스로는 `/user/...`, `/dev/...` 절대 경로.
- `.md` 에서 `<`, `{` 는 코드 스팬으로 감싼다 (MDX 파싱).
- 코드와 문서가 어긋나면 코드를 기준으로 문서를 고친다. 코드 내용을 문서에 쓸 땐 실제 소스를 확인.
- 문서는 한국어, 코드 식별자는 원문 그대로.
- 관련 skill: `write-docs`
